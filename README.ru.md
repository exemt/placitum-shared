# Placitum shared

[English](README.md) · Русский

Общие Go-пакеты процессов Placitum: инспекторов, сервисов и агентов. Пакет попадает сюда, только
если у него один смысл для всех процессов и один хозяин. Всё, что компонент делает по-своему,
остаётся в компоненте.

## Пакеты

| Пакет | Что делает |
| --- | --- |
| `pulse` | кадр присутствия на `WAF_STATUS`: кто работает, где и сколько. Не вердикт и не healthcheck. `Frame` встраивается в кадр любого процесса, `Message` — кадр инспектора |
| `host` | снимок машины для кадра: ядра, память, нагрузка |
| `flow` | счётчики ввода-вывода: сколько принято и отдано за окно |
| `loglevel` | уровни журнала nginx (`debug`…`alert`), их разбор и стартовый порог из переменной процесса |
| `logkit` | журнал сервиса: строки в `waf.log` пакетами `kind=log`, живой порог по документу `policy/log-levels` |
| `dataset` | запись в активные наборы через keeper: синхронно у HTTP-процессов, в фоне у инспекторов |
| `netinfo` | клиент справочника сетей: анонсы, состав системы, кэш и отрицательный кэш |
| `geopb` | сгенерированный gRPC-клиент справочника сетей; `geo.proto` — копия контракта, хозяин которого справочник сетей |

## Как подключить

```go
import "github.com/exemt/placitum-shared/pulse"
```

```sh
go get github.com/exemt/placitum-shared@vX.Y.Z
```

Компонент фиксирует версию в своём `go.mod` и поднимает её, когда ему нужно.

Кадр присутствия у каждого процесса свой: у инспектора адреса в нём живые наборы, у капчи —
счётчики вердиктов, у keeper — наборы, у агента Redis — снимок хранилища. Общая часть от этого не
растёт. Процесс встраивает `pulse.Frame` (сервис) или `pulse.Message` (инспектор) в свою структуру
и шлёт её `pulse.PublishFrame`; поля лягут в один объект JSON.

## Чего здесь нет

Решений инспектора: профилей, условий, вердиктов, порогов и политики. Для этого и есть компонент.

## Версии

Семантическое версионирование. Мажорная версия не ломается ради удобства: полтора десятка
компонентов разом не переписать. Контракт шины меняется в обратном порядке: сначала все читатели,
потом писатели.
